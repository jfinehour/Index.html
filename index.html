Leverage ceiling weight100% Ceiling
Blends Ceiling and Projection for the leverage score used to build Small/Large Field lineups. 100% is pure ceiling (max upside, more volatile); lower it to temper leverage with a player's median outcome too.
Minimum projection (GPP only)1.0 pts
Excludes players below this projection from Small/Large Field lineups entirely. A near-zero-ceiling player never scores well enough to be genuinely preferred, but the builder can still use one as a last-resort salary-dump when nothing else fits — this stops that. Projection and Ceiling tabs are unaffected; set to 0 to disable.
Minimum salary used (GPP only)70% ($35,000)
Requires Small/Large Field lineups to spend at least this share of the salary cap, so leverage-driven picks don't leave excessive cap space unused. In Showdown, the true achievable maximum is often well below 100% of the cap — just the two teams' depth charts, not a full slate — so pushing this too high can return zero lineups; the default leaves real headroom. Projection and Ceiling are unaffected; set to 0 to disable.
Max players from one team (Classic GPP only)Off
Caps how many total players (including the QB) can come from a single team in Small/Large Field lineups. Set below Stack size + 1 and it'll conflict with your own stack requirement, producing zero lineups — the stack is checked first. Doesn't apply to Showdown, where Roster Structure already controls the per-team split directly. Set to 0 to disable.

Stack sizeQB + 1
Number of same-team teammates rostered alongside the QB (RB/WR/TE only — never the defense). Push to 2 or 3 to target games you expect to blow past the Vegas total.
Secondary game stackOff
A second game stack from a different game than your QB's: RB/WR/TE with at least one player from each team in that game. 2 players = one from each side; 3 players = both sides plus one more.
Tertiary game stackOff
A third game stack, same rules (both teams, a game not already used). Requires Secondary to be on first.
